# Lumére

Sitio de velas artesanales construido con React, TypeScript y Vite.

Incluye un carrusel visual de aromas, un catálogo con búsqueda y filtros,
fichas de producto y un prototipo de carrito de compras en el navegador.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Estructura

```text
src/
├── components/       # Secciones visuales; cada componente incluye su CSS
├── data/             # Catálogo y contenido editable
├── hooks/            # Lógica reutilizable de React
├── styles/           # Tokens de diseño y estilos base
├── types/            # Tipos compartidos
├── utils/            # Formateadores reutilizables
├── App.tsx           # Composición de la página
└── main.tsx          # Entrada de React
```
